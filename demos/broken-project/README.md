# Broken project

A tiny project with one bug, for Code mode. Copy this folder somewhere else first, so Pi edits the copy:

```bash
cp -R demos/broken-project /tmp/broken-project
```

Then pick `/tmp/broken-project` in Code mode and ask: "Running python3 main.py crashes. Find and fix the bug, then
run it again to prove it works."

Expected after the fix: `python3 main.py` prints `Total: 3836.46` and `OK`.
